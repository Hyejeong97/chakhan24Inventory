두 파일을 업로드한 뒤 계산 버튼을 눌러 주세요.
* 결과의 기준 목록은 판매물품입니다.
* 도매분류는 도매분류 아래에 1순위 | 2순위 형태로 표시합니다.
* 바코드 오른쪽에 제조사 / 분류 컬럼을 추가했습니다.
* 컬럼 정렬은 누른 순서대로 다중 정렬됩니다. 예: 1순위 클릭 → 제조사 클릭 시, 1순위가 1차 기준이고 제조사가 2차 기준입니다.
* 같은 컬럼을 다시 클릭하면 해당 기준의 오름차순/내림차순이 전환됩니다.
* 검색창에서 상품명, 바코드, 도매분류 1순위·2순위를 모두 검색할 수 있습니다.
* 1순위끼리 정렬 버튼을 누르면 같은 도매분류 1순위 상품끼리 모아서 정렬됩니다.
* 분류별 매출과 메뉴별 매출현황 두 양식을 자동 인식합니다.
* 분류별 매출의 대분류 행은 사용하지 않습니다.
* 동일 바코드가 매출 파일에 여러 번 있으면 판매수량을 합산합니다.
* 구매예정수량(C)은 판매수량(B)과 동일하게 계산하되, 추천수량(A)을 초과하지 않습니다.
* 예산단가는 판매물품 데이터의 금액을 사용하며, 예상구매금액 = 구매예정수량 × 예산단가로 계산합니다.
* 분류별 매출에서 찾지 못한 기준 상품은 판매수량을 0으로 계산합니다.
* 재고수량은 음수도 그대로 표시합니다. 예: 추천 5, 판매 8 → -3
